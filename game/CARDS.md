## 표기 범례

| 표기 | 의미 |
|------|------|
| 물리 N | 물리 N 데미지 (ATK 스탯 합산) |
| 마법 N | 마법 N 데미지 (MGC 스탯 합산) |
| 방어막 N | N 만큼 피해 흡수 방어막 (1턴 유지) |
| HP +N | N 만큼 HP 회복 |
| 공격력 ±N (xt) | 공격력 증감 x턴 |
| 방어력 ±N (xt) | 방어력 증감 x턴 |
| 드로우 +N | 다음 턴 드로우 N장 추가 |
| 독 Nt | N턴 동안 매 턴 독 데미지 |
| 마비 Nt | N턴 동안 행동 불가 |
| 약화 25% | 데미지 출력 25% 감소 (1턴) |
| 회피 50% | 공격 50% 회피 (1턴) |
| 차단 1회 | 공격 1회 차단 |
| [전체] | 전체 적 대상 |
| [파티] | 아군 파티 전체 대상 |
| ⭐ | 시그니처 카드 (트랙 최강 카드) |
